# Assuntos dos e-mails

Em Supabase → Authentication → Emails → Templates, cada modelo recebe o assunto abaixo e o HTML do arquivo indicado.

| Modelo no Supabase | Assunto | Arquivo |
| --- | --- | --- |
| Reset password | Código para redefinir sua senha · Plataforma MAC | `recuperar-senha.html` |
| Invite user | Seu acesso à Plataforma MAC | `convite.html` |
| Confirm signup | Confirme seu e-mail · Plataforma MAC | `confirmar-cadastro.html` |
| Magic link | Seu link de acesso · Plataforma MAC | `link-de-acesso.html` |
| Change email address | Confirme seu novo e-mail · Plataforma MAC | `trocar-email.html` |
| Reauthentication | Seu código de confirmação · Plataforma MAC | `codigo-de-confirmacao.html` |
